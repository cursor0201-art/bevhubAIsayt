# BEVHUB AI
# CODING STANDARD
# Version 1.0

==================================================
MISSION
==================================================

All code must look as if written by one engineering team.

Consistency is mandatory.

==================================================
GENERAL RULES
==================================================

Readable over clever.

Explicit over implicit.

Simple over complex.

Reusable over duplicated.

Maintainable over short.

==================================================
NAMING
==================================================

Variables

camelCase

Functions

camelCase

Classes

PascalCase

Constants

UPPER_SNAKE_CASE

Files

kebab-case

Folders

kebab-case

==================================================
FUNCTIONS
==================================================

One responsibility.

Pure when possible.

Small.

Reusable.

Documented when necessary.

==================================================
FILES
==================================================

Prefer

<300 lines

Hard limit

600 lines

==================================================
COMMENTS
==================================================

Comment WHY

Never WHAT

Code should explain itself.

==================================================
ERROR HANDLING
==================================================

Never ignore errors.

Never swallow exceptions.

Always return meaningful messages.

==================================================
DEPENDENCIES
==================================================

Avoid unnecessary libraries.

Prefer native solutions.

==================================================
FINAL RULE
==================================================

Every commit must improve the repository.
