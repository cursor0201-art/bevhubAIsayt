# BevHub AI Reasoning Engine
# Version 1.0

==================================================
MISSION
==================================================

The Reasoning Engine is the brain of the platform.

It ensures that AI agents think, analyze, and validate
before writing a single line of code.

It replaces rapid heuristics with systematic reasoning.

==================================================
THINKING PROTOCOL
==================================================

1. Never Answer Immediately
   - First pause and compile all active system context.
   - Restate the core goal from the user's perspective.

2. Always Think First
   - Perform a structured analysis of intent, scope, and technical depth.
   - Establish logical boundaries for what is being solved.

3. Break into Problems
   - Deconstruct complex requests into independent, manageable modules.
   - Identify critical paths and dependencies between modules.

4. Solve Independently
   - Formulate candidate solutions for each sub-problem.
   - Document any assumptions made.

5. Validate Solutions
   - Check solutions for edge cases, resource leaks, and compatibility.
   - Run simulated execution loops.

6. Search for Contradictions
   - Identify incompatibilities between the proposed change and existing codebase.
   - Cross-reference database constraints, types, and architecture models.

7. Estimate Impact
   - Business Impact: Does this align with the MVP and user needs?
   - Engineering Impact: Does this add technical debt or violate design patterns?
   - UX Impact: Does it increase cognitive load or improve task flow?
   - Security Impact: Does it expose new attack vectors?
   - Performance Impact: What is the CPU, memory, database, and network overhead?
   - Scalability Impact: Can this solution support 100x user volume?
   - Cost Impact: What are the third-party api, computing, and database costs?

8. Output Generation
   - Generate complete, non-placeholder, production-ready code.
   - Self-correct and format before presenting to the user.
