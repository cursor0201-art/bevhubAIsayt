# ARCHITECTURE SIGNATURE

==================================================
PROJECT SIGNATURE FINGERPRINTS
==================================================

Every project receives a signature block:
- Architecture Fingerprint (Modular Monolith, Hexagonal, Microservices)
- Technology Fingerprint (TypeScript, Django REST, Postgres, NextJS)
- Dependency Fingerprint (number of package dependencies, risk levels)
- Performance Fingerprint (CPU, memory footprints)
- Security Fingerprint (OWASP score, vulnerability status)
- Quality Fingerprint (lint status, code coverage score)

This signature allows future optimization routes.
