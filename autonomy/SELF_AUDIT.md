# SELF AUDIT

==================================================
PRE-COMPLETION QUESTIONNAIRE
==================================================

Before completing any task, check:
1. Did I satisfy the specification?
2. Did I violate the system architecture?
3. Did I increase technical debt?
4. Can this solution be simpler?
5. Can this solution be faster?
6. Can this solution be safer?

If any answer indicates room for improvement, run self-repair before responding to the user.
